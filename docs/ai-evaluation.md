# Evaluación de IA opcional

No se agregó proveedor externo ni se enviaron datos comerciales o personales a servicios de IA.

| Función | Implementación actual | Posible siguiente paso |
| --- | --- | --- |
| Correos profesionales | Plantillas deterministas reutilizables, tokens y correcciones | Redacción opcional con aprobación humana; desidentificar nombres, CI, contratos y montos antes de procesar externamente. |
| Indicadores | Cálculos exactos y fuentes visibles en el dashboard | Explicaciones gerenciales basadas en los resultados calculados, sin permitir que el modelo sustituya fórmulas. |
| Inconsistencias | Detección local de coincidencias de venta y separación de proyección/actual | Servicio de auditoría conectado al CRM con permisos de solo lectura. |
| Productividad | Reglas heredadas preservadas; discrepancias documentadas | Confirmar política de negocio antes de automatizar interpretaciones o incentivos. |

Para habilitar IA se necesita elegir proveedor, autorizar qué datos pueden salir, configurar credenciales exclusivamente en servidor, límites de costo y retención, y una revisión explícita antes de enviar correos. Estas funciones opcionales no bloquean los módulos existentes.
